# Development history

The initial 27 commits are a retrospective import of a project developed before Git was initialized. Their author timestamps, distributed across 12-18 October 2026 in the Europe/Madrid time zone, are approximate development-phase labels rather than an original log of Git activity. Committer timestamps record when the import was actually performed.

The import groups existing work by feature. Intermediate import snapshots can depend on files introduced by later commits; the final imported state is the validated project. Original experiment timestamps, recorded source snapshots, and evaluation artifacts have been preserved without rewriting them to match the Git timeline.

The final import includes the English usage guide, the local application launcher, and checks that scan publication candidates and staged contents for credentials.
